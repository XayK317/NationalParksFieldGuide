# National Parks Field Guide

A simple React website for exploring national parks.

## Run locally

```bash
npm install
npm run dev
```

## Features

- Home, parks, park details, About, and Not Found pages
- React Router navigation
- Park details with highlights and a back button
- Netlify refresh redirects
