# National Parks Field Guide

A simple React website for exploring national parks.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Netlify

Connect the repository to a Netlify site and deploy from the repository root.
The included `netlify.toml` selects Node.js 24, runs `npm run build`, and
publishes `dist`. The `public/_redirects` file is copied into the build so
React Router pages also work when refreshed or opened directly.

## Features

- Home, parks, park details, About, and Not Found pages
- React Router navigation
- Park details with highlights and a back button
- Netlify refresh redirects
